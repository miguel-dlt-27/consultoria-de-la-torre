# Sitio profesional — Miguel de la Torre

Archivos para publicación en GitHub Pages.

## Publicación
1. Crea un repositorio público.
2. Sube `index.html`, `robots.txt` y `sitemap.xml` a la raíz.
3. Ve a Settings → Pages.
4. Selecciona Deploy from a branch.
5. Branch: `main`; Folder: `/(root)`.
6. Guarda.

## Pendiente
Cuando se conozca el nombre de usuario/repositorio definitivo:
- añadir URL canónica a `index.html`;
- añadir `og:url`;
- completar `sitemap.xml`;
- añadir la URL del sitemap a `robots.txt`.
